# Session records

One file per working session, named `YYYY-MM-DD-HHMM-slug.md` with `HHMM` the
session's start in UTC. Each says what changed in goodcopy (PageKit included)
and why, in terms of the capability, never of whoever asked for it
(`CLAUDE.md`). A record is never edited by a later session; a correction goes
in the later session's own file.
